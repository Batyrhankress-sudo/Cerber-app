# Как получить APK «Цербер» с телефона

1. Создайте аккаунт на GitHub и новый репозиторий.
2. Загрузите в репозиторий содержимое этой папки.
3. Откройте вкладку Actions.
4. Выберите «Build Cerber APK».
5. Нажмите «Run workflow».
6. После завершения откройте готовый запуск и скачайте artifact:
   `cerber-release-apk`
7. Внутри будет `app-release.apk`.

Важно: ZIP нельзя просто переименовать в APK. APK нужно собрать из проекта.
Сборка выполняется в GitHub Actions, поэтому Android Studio на телефоне не нужна.
