# Цербер 1.3
MVP-прототип приложения безопасности для Android/iOS.

## Новое
- Каталог типов угроз
- Карточка конкретной угрозы
- Уровни риска и время обновления
- История предупреждений
- Фильтрация предупреждений
- Инструкции по действиям
- Экстренные контакты
- Карта-заглушка для дальнейшего подключения реальных данных

## Запуск
flutter pub get
flutter run

Это прототип. Данные об угрозах демонстрационные и не являются официальными предупреждениями.
